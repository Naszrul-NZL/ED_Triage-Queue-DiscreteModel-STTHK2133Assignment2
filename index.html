STTHK2133 Modeling & Simulation

Emergency Department Triage Simulation

A fixed patient cohort is monitored hour by hour using utility, SoftMax assignment, queue waiting time, and deterioration feedback.

Current Tick t = 0 1 tick = 1 hour

Patient Input

Use the seven-patient preset cohort or enter your own anonymous patient data.

Simulation Controls

The model advances in one-hour ticks.

Core rules U*ij = (alpha x Si + beta x Wj) - gamma x (nj / Cj) P(j|i) = exp(U*ij) / sum exp(U*ik) Wq = nj / muj St = Sinitial + (delta x wait_time)
